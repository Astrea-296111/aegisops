## 版本 C：60 秒介绍

我做了一个面向微服务排障的 Python Agent。它接到故障后读取指标、日志和链路，补查依赖服务，再输出带 Evidence ID 的根因报告。模型负责计划和假设，普通后端代码负责授权、预算、租约和执行。我比较重视进程故障和安全边界：worker 中断后可以从数据库恢复，旧 worker 会被 fencing token 拒绝；修复必须经过 operator 审批并绑定精确参数，演示资源更新和幂等回执同事务提交。目前在 10 个手写合成场景和 Fake Provider 上做了可复现回归；两个基线同样满分，所以我没有宣称诊断精度提升。下一步是扩展独立复杂样本并接真实模型。
